A Queue is a linear data structure that adheres strictly to the First-In, First-Out (FIFO) principle. The element inserted first is guaranteed to be the first element removed. Elements enter via enqueue() at the Rear and leave via dequeue() from the Front.

Time & Space Complexity
Operation Complexity Description
ENQUEUE O(1) Insert at rear pointer
DEQUEUE O(1) Delete at front pointer
PEEK / FRONT O(1) Inspect first element
REAR O(1) Inspect last element
SIZE / EMPTY O(1) Constant index math
SEARCH O(n) Linear pass across items
QueueFlow achieves true O(1) dequeues using front/rear index hashing instead of Array.shift() which is O(n).

Viva Voce & Academic Explanations
1. What is a Queue and what principle does it follow?
A Queue is a linear data structure that operates under the FIFO (First-In, First-Out) principle. The first item inserted into the queue is the first item to be removed. Insertions occur at the Rear, while deletions occur at the Front.
2. What is the difference between FRONT and REAR?
FRONT points to the index of the first item waiting in line. It is where dequeue() or peek() operates. REAR points to the next available slot where enqueue() adds new items.
3. Why does Array.shift() cause O(n) dequeue time in JS?
When using standard arrays, removing the first item with array.shift() requires the JS engine to re-index and shift every single remaining element one position to the left in memory, taking O(n) time. By using pointer indices (frontIndex and rearIndex) with an object/map, our implementation achieves O(1) constant time.
4. What is Queue Underflow and Overflow?
Underflow: Attempting to remove (dequeue) an item when the queue is already empty. Our app catches this and notifies the user.
Overflow: Attempting to insert (enqueue) into a fixed-capacity queue when it is already full (applies to bounded/circular queues).
5. What are the key real-world applications of queues?
CPU round-robin scheduling, OS printer spooling, network routers packet buffers, breadth-first search (BFS) graph traversals, and asynchronous message broker queues (RabbitMQ, Kafka).
